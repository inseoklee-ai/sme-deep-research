# 기술 수용 모델(TAM)의 변수

기술 수용 모델(TAM)은 사용자가 기술을 수용하는 과정을 설명하는 이론이다. 이 모델은 특정 변수들이 기술 사용에 미치는 영향을 강조한다. 특히, 인식된 유용성과 인식된 사용 용이성이 주요 요소로 작용한다.

## 1. TAM의 주요 요소  _(혼자)_

기술 수용 모델(TAM)은 사용자의 태도와 행동 의도가 기술 사용에 미치는 영향을 강조한다 «Technology acceptance model». TAM의 주요 요소로는 인식된 유용성(PU)과 인식된 사용 용이성(PEOU)이 있다 «Technology acceptance model». 인식된 유용성은 사용자가 기술을 사용했을 때 얻는 이점을 의미한다 «Technology acceptance model». 인식된 사용 용이성은 사용자가 기술을 사용하는 데 드는 노력을 의미한다 «Technology acceptance model». TAM은 Fred Davis에 의해 개발되었으며, Ajzen과 Fishbein의 이론을 확장한 것이다 «Technology acceptance model». TAM은 여러 연구에서 검증되었고, TAM2와 UTAUT와 같은 확장 모델이 제안되었다 «Technology acceptance model».

## 맺음말

TAM은 기술 수용의 복잡한 과정을 이해하는 데 중요한 기초를 제공한다. 그러나 이 모델은 사회적 과정이나 비용과 같은 다른 요소를 간과한다는 비판도 존재한다. 따라서 TAM을 활용할 때 이러한 한계를 인식하는 것이 중요하다.
